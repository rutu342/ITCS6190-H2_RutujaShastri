# ITCS 6190 Hands-On L3: Flask Web App with Docker Compose

## Overview

This hands-on exercise demonstrates how to build and run a Python Flask web application using Docker and Docker Compose. The application uses Redis as a separate container to maintain a page-visit counter.

The project includes two services:

- **Web:** Python Flask application
- **Redis:** Redis cache used to store the visit count
